About

An open-source, reproducible mirror of 15 public GIS layers from the St. Johns River Water Management District (SJRWMD), which covers 18 counties of northeast and east-central Florida.

Why these 15 layers

Five polygon, five point and five line layers, chosen for usefulness and for clean API use: stable IDs, typed date and status fields, and easy spatial joins. Permits (ERP, CUP, wells, reuse), monitoring stations, district lands, 2020 land use and the stream network.

How it works

  1. A Python harvester pages each ArcGIS REST layer by OBJECTID and loads typed tables into PostGIS, with provenance on every row.
  2. Every load is checked against the server's feature count. All 15 match.
  3. tippecanoe turns each layer into a single PMTiles file, served directly by GitHub Pages and drawn with MapLibre GL. No tile server.
  4. GDAL exports GeoPackage, GeoParquet and CSV for the downloads.

Full walkthrough: How it was loaded into PostGIS. Source code: github.com/knightchrism/sjrwmd-open-data (MIT).
